# MySQL Database Sanitizer - Быстрый старт

## 🚀 Запуск (3 команды)

```bash
# 1. Клонируйте репозиторий
cd /project-data-sanitizer

# 2. Создайте дамп вашей базы данных
mysqldump -h production.db.internal -u root -p > dump.sql

# 3. Запустите санитизацию
docker compose build && docker compose run --rm greenmask
```

Готово! 🎉 Результат в `./output/sanitized.sql.gz`

---

## 📝 Что изменилось в этом решении

### ✅ **Упрощено:**
- Один `docker-compose.yml` вместо нескольких сервисов
- `dump.sql` → один файл для ввода
- Выход → один заархивированный SQL файл
- Нет необходимости в отдельном продакшене MySQL контейнере

### ✅ **Экономия на LLM:**
- Используется **bailian/qwen3.5-flash** — самая дешёвая модель ($0.10/1M tokens)
- В 3 раза дешевле MiniMax M2.5
- Сохранение маппинга для обратной совместимости без лишних вызовов API

### ✅ **Консистентность связей:**
- PK/FK не меняются (оставляют структуру intact)
- PII поля меняются с сохранением логики: "Иван Иванов" везде становится "Петр Петров"
- Mapping JSON позволяет восстановить связи при необходимости

## 📊 Файлы проекта

| Файл | Назначение |
|------|------------|
| `config.yaml` | Правила трансформации (можно редактировать) |

## 💡 Следующие шаги

Если нужно добавить:
1. **Новое поле для маскировки** → добавьте в `config.yaml`
